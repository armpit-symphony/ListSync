# ListSync

ListSync is a private shared shopping list for a household. The people using a list are not charged. A retailer side can publish local example prices; monthly and yearly retailer subscriptions are the intended future funding model, and those fee amounts are unset.

This repository continues the existing FastAPI and MongoDB app. It is a household pilot, not a public production service.
